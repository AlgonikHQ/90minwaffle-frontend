# Security

Found something that looks wrong, such as a bug, an exposed file or anything that could put users or the site at risk? Please report it privately using the contact email on the site's About page, rather than opening a public issue.

Please don't run automated scanners or load tests against the live site.

Confirmed issues are fixed as quickly as possible, and reporters are credited in the changelog if they wish.

No payment details are stored anywhere, and the site never asks for them.
